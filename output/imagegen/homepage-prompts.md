# Ana sayfa görselleri

Yöntem: Yerleşik `image_gen` aracı. Altı görsel ayrı istemlerle üretildi.

Tarih: 19 Ekim 2026.

Kullanım: Ana sayfadaki iki proje kapağı, ekip alanı ve üç blog kapağı. Dosyalar kalite 85 ile 1536 × 1024 WebP olarak kaydedildi. Mevcut örnek kapaklar ana sayfada yeni görsellere yönlendirilir; yönetim panelinden yüklenen özel kapaklar önceliğini korur.

## fleet-platform

Dosya: `frontend/public/images/home/fleet-platform.webp`

```text
Use case: product-mockup
Asset type: featured logistics software project cover for a premium Turkish software studio website
Primary request: create a beautifully art-directed photorealistic product visualization of a fleet and shipment tracking platform.
Scene/backdrop: a clean matte dark navy studio surface, extremely subtle blue ambient light, no busy props.
Subject: a large elegant silver desktop monitor at a slight three-quarter angle, showing a polished dark fleet tracking dashboard with a map of roads, blue location pins, a compact sidebar and restrained data cards; a small matching tablet in the foreground. UI text can be minimal small abstract lines, the image's focus is the software and industrial design.
Composition/framing: landscape 3:2, the devices centered with generous 12% breathing room on all sides so the image crops cleanly to a website card, tangible shadows, cinematic editorial product photography.
Lighting/mood: soft directional studio light, confident and precise, rich contrast without crushed shadows.
Color palette: ink navy, slate silver, cool periwinkle-blue interface accents matching a dark website.
Materials/textures: brushed aluminum, realistic reflective glass and a tactile matte surface.
Constraints: one continuous image, no collage, no promotional headings, no logos, no watermark, no decorative code, no people.
```
